# Contributing

Suggestions and improvements are welcome.

1. Open an issue describing the problem or feature.
2. Include the ESP32 board, sensor/module version, wiring, and steps to reproduce.
3. For firmware changes, state whether the code was compiled and whether it was tested on physical hardware.
4. Keep credentials, Wi-Fi passwords, tokens, and personal data out of commits.

Please distinguish simulated or code-reviewed behavior from physically verified behavior.
